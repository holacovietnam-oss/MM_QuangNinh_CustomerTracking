# MM Customer Tracking 1.0

App PWA cho iOS/Android để ghi nhận khách tham khảo, chốt/không chốt, lý do và ghi chú. Dữ liệu hiện lưu trên thiết bị; có xuất Excel `.xls`.

## Danh mục đã nạp
- 56 NVBH/PG từ NVBH_MMQuangNinh2026.xlsx
- 10 nhóm ngành hàng từ 10_NGANHHANG.xlsx

## Cài trên điện thoại
PWA cần được đặt trên một website có HTTPS. Mở đường dẫn trên iPhone/Android và chọn Add to Home Screen / Install App.

## Lưu ý phiên bản 1.0
Mỗi thiết bị lưu dữ liệu riêng. Để tất cả nhân viên dùng chung một kho dữ liệu, triển khai `backend_google_apps_script/Code.gs` và cấu hình endpoint trong bản 1.1.
